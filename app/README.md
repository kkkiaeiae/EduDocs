# EduDocs — ЖОО оқу үдерісі құжаттарын есепке алу деректер базасы

«Деректер базасы және SQL сұратымдар» пәні бойынша курстық жұмыстың бағдарламалық бөлігі.
Тақырып: **Мемлекеттік жоғары оқу орнындағы оқу үдерісіне қатысты құжаттарды есепке алуға арналған деректер базасын құру**.

Құралдар: Python 3.9+ (тек стандартты кітапхана: `sqlite3`, `http.server`, `hashlib`), SQLite 3, PyCharm,
кез келген браузер. Диаграмма салу үшін ғана `matplotlib` қажет (`step12_er_diagram.py`).

## Деректер базасы: 6 кесте

| Кесте | Мазмұны |
|---|---|
| `departments` | бөлімшелер (кафедралар, тіркеу офисі) |
| `document_types` | құжат түрлері: код, атауы, санаты, сақтау мерзімі |
| `documents` | құжаттарды тіркеу журналы — негізгі кесте |
| `students` | білім алушылар |
| `document_students` | құжат пен білім алушы арасындағы «көпке-көп» байланыс |
| `users` | қосымшаның пайдаланушылары (логин, құпиясөз хэші, рөлі) |

Бұдан басқа: 2 индекс, 1 көрініс (`v_registry`), 1 триггер (`trg_protect_approved`).

## Жобаның файлдары

| Файл | Мақсаты |
|---|---|
| `schema.sql` | кестелерді құратын SQL командалары |
| `seed_data.py` | бастапқы демонстрациялық деректер (тұлғалар ойдан алынған) |
| `database.py` | қосылу, базаны құру, қазақ әліпбиі бойынша сұрыптау, нәтижені кесте түрінде шығару |
| `step01_connect.py` … `step12_er_diagram.py` | PyCharm-де кезең-кезеңімен орындалатын жұмыстар |
| `run_all_steps.py` | барлық қадамдарды қатарынан орындап, нәтижені `outputs/` бумасына сақтайды |
| `app.py` | веб-сервер: жүйеге кіру, рөлдер, JSON API; іске қосылғанда браузерді ашады |
| `repository.py` | веб-қосымшаның барлық SQL сұратымдары және 8 дайын есеп |
| `auth.py` | құпиясөзді хэштеу (PBKDF2) және тексеру |
| `web/` | интерфейс: `index.html`, `style.css`, `app.js` |

## PyCharm-де іске қосу

1. **File → Open** → `EduDocs` бумасы. Python 3.9 немесе жаңа нұсқасы таңдалады.
2. Скрипттерді ретімен іске қосыңыз (тінтуірдің оң жағы → **Run** немесе `Ctrl+Shift+F10`):
   `step01_connect.py` → `step02_create_tables.py` → … → `step12_er_diagram.py`.
3. Веб-қосымша: `app.py` → **Run**. Браузер `http://127.0.0.1:8770/` адресін өзі ашады.
   Тоқтату — PyCharm-дағы қызыл **Stop** батырмасы.
