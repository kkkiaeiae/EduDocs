# EduDocs — оқу үдерісі құжаттарын есепке алу деректер базасы

«Деректер базасы және SQL сұратымдар» (DBSQLS 2214) пәні бойынша курстық жұмыс.
Л.Н. Гумилев атындағы Еуразия ұлттық университеті, Жасанды интеллект технологиялары кафедрасы, 2026.

**Тақырыбы:** Мемлекеттік жоғары оқу орнындағы оқу үдерісіне қатысты құжаттарды есепке алуға арналған деректер базасын құру

**Орындағандар:** Ербол Елқұт, Авьдал Бахатбек (6B06112 – «Жасанды интеллект технологиялары», 2-курс)
**Ғылыми жетекші:** Елибаева Г.К.

Жобаның сипаттамасы бар бет: GitHub Pages (`docs/index.html`).

## Құрамы

| Бума / файл | Мазмұны |
|---|---|
| `app/` | PyCharm жобасы: SQLite деректер базасы, 12 қадамдық скрипт және веб-қосымша |
| `report/` | Курстық жұмыс (DOCX, PDF) және қорғау презентациясы (PPTX) |
| `docs/` | GitHub Pages беті және скриншоттар |
| `start.py` | Веб-қосымшаны бір батырмамен іске қосу |

## Іске қосу

Қажет: Python 3.9 немесе жаңа нұсқасы. Веб-қосымша тек стандартты кітапханамен жұмыс істейді;
`step12_er_diagram.py` үшін ғана `matplotlib` керек (`pip install matplotlib`).

```bash
python start.py          # немесе: cd app && python app.py
```

Браузер `http://127.0.0.1:8770/` адресін өзі ашады.

| Рөлі | Логин | Құпиясөз | Қолжетімді беттер |
|---|---|---|---|
| Әкімші | `admin` | `Admin2026` | Басты бет, Құжаттар тізілімі, Білім алушылар, SQL есептер; құжаттарды енгізу, өзгерту, жою |
| Қонақ | `qonaq` | `Qonaq2026` | Басты бет, Құжаттар тізілімі, SQL есептер; тек бекітілген және мұрағаттағы құжаттар |

PyCharm-да қадамдарды ретімен орындау: `app/step01_connect.py` → … → `app/step12_er_diagram.py`
(әр файл: тінтуірдің оң жағы → Run). Барлығын қатарынан: `app/run_all_steps.py`.

## Деректер базасы: 6 кесте

| Кесте | Мазмұны |
|---|---|
| `departments` | бөлімшелер (кафедралар, тіркеу офисі) |
| `document_types` | құжат түрлері: код, атауы, санаты, сақтау мерзімі |
| `documents` | құжаттарды тіркеу журналы — негізгі кесте |
| `students` | білім алушылар |
| `document_students` | құжат пен білім алушы арасындағы «көпке-көп» байланыс |
| `users` | қосымшаның пайдаланушылары (логин, құпиясөз хэші, рөлі) |

Бұдан басқа: 4 сыртқы кілт (RESTRICT, CASCADE), 2 индекс, 1 көрініс (`v_registry`),
1 триггер (`trg_protect_approved` — бекітілген құжатты жоюға тыйым салады).

## 12 қадам (PyCharm)

| Скрипт | Міндеті |
|---|---|
| `step01_connect.py` | ДБ құру, қосу және ажырату (connect, close, ATTACH, DETACH) |
| `step02_create_tables.py` | кестелер мен байланыстарды құру |
| `step03_insert.py` | деректерді енгізу, шектеулерді тексеру |
| `step04_update_delete.py` | деректерді өзгерту және жою (CASCADE, RESTRICT, триггер) |
| `step05_select_simple.py` | бір кестеден іріктеу |
| `step06_filter.py` | сүзгілеу (WHERE, LIKE, BETWEEN, IN, IS NULL) |
| `step07_group_sort.py` | топтау және сұрыптау (GROUP BY, HAVING, ORDER BY, KAZAKH) |
| `step08_join.py` | бірнеше кестеден іріктеу (INNER JOIN, LEFT JOIN) |
| `step09_subquery_union.py` | кірістірілген сұратымдар, UNION |
| `step10_view_trigger.py` | көрініс және триггер |
| `step11_transaction_index.py` | транзакциялар және индекс (EXPLAIN QUERY PLAN) |
| `step12_er_diagram.py` | деректер базасының диаграммасы |

> Тұлғалардың аты-жөндері мен деректері ойдан құрастырылған және тек оқу мақсатында қолданылады.
